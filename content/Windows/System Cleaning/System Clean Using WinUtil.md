Windows Utility is a tool created by Chris Titus to help debloat windows.
For the original repo please follow this [link](https://youtu.be/BLBvbMtjyAQ)

___ 
## 1. Open PowerShell as Administrator

![[Pasted image 20260616152714.png]]


___
## 2. Start WinUtil 

``` bash
irm https://christitus.com/win | iex
```

Paste the above code and hit enter!
![[Pasted image 20260616152944.png]]

___
## 3. Debloat Windows with the Tweaks TAB

Click in the tweaks tab followed by Standart settings. Start with this as they are the base ones that will not affect any system service that is needed just bloat. 

 ![[Pasted image 20260616153304.png]]

In the right menu **Customize Preferences** toggle the ones you need to be on, this allows to control what is visible on the windows UI 

With all selected click in **Run Tweaks** and watch the console logs as it does the work.
