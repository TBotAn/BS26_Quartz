## 3. Add User for Next Cloud

1.  Go to Accounts
   ![[Pasted image 20260615165219.png]]
2. Click In add New Account
   ![[Pasted image 20260615165239.png]]
3. Set the details for the account and save them on the password manager
   As well as adding the member to a group called **Guests**.
   Leave the rest of details empty and change the **Quota** to unlimited or a high value. 
   ![[Pasted image 20260615165427.png]]
4. Share a folder with the user by going to files and clicking the icon in the image bellow, and in internal users adding the respective user. 
   ![[Pasted image 20260615165538.png]]
